# Task 2 — Pre-Project Data Profiling & Audit

## 📌 Project Overview

This project is part of my **Data Analytics learning journey** under the **PlaceMux – Phase 1: Industry Immersion** program.

The objective of this task was to perform a **pre-project data profiling and quality audit** before starting any analysis. The focus was on understanding the dataset structure, identifying data-quality issues, and preparing the data for further analysis.

---

## 🎯 Objective

The main objectives of this task were to:

* Understand the structure and size of the dataset
* Inspect columns and their data types
* Identify missing values
* Detect duplicate records
* Check unique values and categorical variables
* Identify potential data-quality issues
* Examine numerical columns and their basic statistics
* Understand the overall condition of the dataset before analysis

## 🔍 Work Performed

### 1. Dataset Inspection

I started by loading the dataset into Pandas and examined:

* Number of rows and columns
* Column names
* Data types
* Sample records
* Overall dataset structure

### 2. Data Quality Audit

The dataset was checked for common quality problems, including:

* Missing values
* Duplicate records
* Incorrect or unexpected data types
* Unique values
* Potential inconsistencies

### 3. Numerical Data Analysis

For numerical columns, I reviewed:

* Count
* Mean
* Standard deviation
* Minimum value
* Maximum value
* Quartiles

This helped identify the general distribution and possible unusual values in the dataset.

### 4. Categorical Data Analysis

Categorical columns were examined using:

* Unique-value counts
* Frequency distributions
* Value consistency checks

This provided an initial understanding of the categories present in the dataset.

---

## 📊 Key Findings

The profiling process helped establish a clear understanding of the dataset before beginning deeper analysis.

The audit focused on:

* Dataset dimensions
* Data types of individual columns
* Missing-value patterns
* Duplicate records
* Numerical-variable statistics
* Categorical-variable distributions
* Potential data-quality concerns

These findings provide a foundation for the next stages of the data-analysis workflow.
